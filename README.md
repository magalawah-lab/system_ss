# BSSS - School Management System

A comprehensive school management system built with Next.js, TypeScript, and Supabase.

## Features

- 👨‍🏫 **Teacher Dashboard** - Teachers can view assigned classes, subjects, and assessments
- 📊 **Student Management** - Manage student records, enrollments, and profiles
- 📝 **Assessment & Marksheet** - Create assessments and enter scores
- 📈 **Report Builder** - Generate report cards for O-Level and A-Level
- 🎓 **Academic Years & Terms** - Organize data by academic periods
- 📁 **Backup & Restore** - Full database backup and restore functionality

## Tech Stack

- **Frontend**: Next.js 14, React, TypeScript
- **Backend**: Supabase (PostgreSQL)
- **Authentication**: Supabase Auth (JWT)
- **Styling**: CSS-in-JS (styled-jsx)
- **State Management**: React Context API

## Prerequisites

- Node.js 18.17 or later
- npm or yarn
- Supabase account (for production)
