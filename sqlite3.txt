**What That Error Means**
- `better-sqlite3` is a native module, and the `.node` binding is its compiled binary.
- When that file is missing, SQLite does not initialize, so DB-backed APIs can fail or fall back to JSON storage instead of `school.db`.
- Impact to you: risk of startup warnings, `503` on writes (without fallback), and inconsistent persistence backend.

**Root Cause Found**
- pnpm had this package in ignored builds (`ignoredBuilds`) in `node_modules/.modules.yaml`, so install scripts for `better-sqlite3` were not producing the binary.
- Your runtime is `Node v24.1.0` / ABI `137`, which is supported by `better-sqlite3@12.9.0`, so the issue was build policy, not unsupported Node.
